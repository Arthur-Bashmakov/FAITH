# План завершения FAITH

## Фактическое состояние

Реализованы Android-клиент на Kotlin и Jetpack Compose, запись и импорт основных
аудиоформатов, предпросмотр, воспроизведение, локализация RU/EN, гостевой режим,
персональная история, регистрация по email или телефону, Яндекс ID и удаление
аккаунта. Production URL задаётся через BuildConfig, а отдельный адрес разрешён
только debug-сборке.

Backend использует FastAPI, PostgreSQL, Redis и AASIST-L. Аудио декодируется во
временной папке и удаляется сразу после анализа. Redis хранит результат 15 минут.
Тишина и простые тональные сигналы отклоняются, постоянная составляющая удаляется,
а усиление тихой речи ограничено. Интерфейс показывает числовую оценку выхода
модели и качественный комментарий, не выдавая оценку за калиброванную вероятность.

## До финальной демонстрации

1. Запустить backend-тесты и Docker Compose в чистой локальной среде.
2. Сделать резервную копию production PostgreSQL.
3. Применить `backend/migrations/001_add_phone_auth.sql`.
4. Добавить `YANDEX_CLIENT_ID` только в серверный `.env`.
5. После отдельного разрешения развернуть backend и проверить health, анализ,
   регистрацию, Яндекс ID, историю и удаление аккаунта.
6. Проверить Яндекс ID и полный пользовательский сценарий на физическом телефоне.
7. Выполнить Android lint, доступные тесты и финальную debug-сборку APK.
8. Зафиксировать результаты ручной проверки в отчёте о выпуске.

## Осознанно оставлено дальнейшим развитием

- подтверждение телефона по SMS и email через письмо;
- Google, VK и Apple OAuth;
- push-уведомления;
- крупный MVVM/Room-рефакторинг без необходимости для текущего прототипа;
- калибровка порогов на независимом размеченном наборе русской речи;
- подписанный магазинный релиз.

После каждого изменения выполняются соответствующие проверки, обновляется
документация и сохраняется существующее рабочее поведение.
